# Waze Latvija Community Website

Clean, fast static website for the Waze Latvia community.

**Domain:** https://www.wazers.lv/

## Features

- Fully responsive (desktop + mobile)
- Bilingual (Latvian default + English) with language switcher
- Modern sleek design (Waze blue + Latvian red accents)
- Pages: Galvena, Jaunumi, Notikumi, Svarīga Informācija, Palīdzība, Kontakts
- Live Waze map embed on homepage
- Contact form
- Sticky header + mobile menu
- Fast loading (no heavy frameworks)

## How to use

1. Upload the entire folder contents to your hosting root (public_html / httpdocs)
2. Or push to GitHub and enable GitHub Pages
3. Replace the car emoji logo with your real Waze + Latvia flag logo (in all HTML files)
4. Update Discord link in kontakts.html when ready
5. For better contact form later: replace mailto with Formspree or similar

## Tech

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- No build step required

- Waze Blue: `#0099FF`
